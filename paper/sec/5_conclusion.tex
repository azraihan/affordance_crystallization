\section{Conclusion}
\label{sec:conclusion}

V-JEPA~2.1's intermediate-layer supervision causes affordance features to crystallize
earlier and in a sparser set of heads than V-JEPA~2.
Pruning to the top-3 heads at the peak layer achieves a $4{\times}$ attention compute
reduction with minimal mAP loss, offering a practical path to efficient affordance-aware
robot perception.
Future work should examine whether the same heads generalize across affordance datasets
and embodiments.
